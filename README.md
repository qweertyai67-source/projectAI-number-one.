# Gamer Cave — демонстрационный лендинг

Интерактивный концепт сайта компьютерного клуба Gamer Cave в Краснодаре. Проект создан на React, TypeScript и Vite.

## Что работает

- адаптивные версии для телефона, планшета и большого экрана;
- выбор филиала, даты, времени, длительности, зоны и игрового места;
- 32 компьютерных места: 20 Standard, 7 VIP и 5 Bootcamp;
- пересчёт демонстрационной стоимости;
- форма подтверждения с маской телефона, валидацией, загрузкой и успешным демо-заказом;
- мобильное меню, тарифы, галерея с просмотром, отзывы, FAQ и модальные документы;
- состояния занятых мест, отсутствия свободных мест и отключённого действия;
- поддержка клавиатуры и режима уменьшенной анимации.

## Запуск

```powershell
pnpm install
pnpm dev
```

Проверки перед публикацией:

```powershell
pnpm typecheck
pnpm lint
pnpm build
```

## Важно перед публикацией

Это демонстрация. Цены, характеристики компьютеров, дополнительные акции, отзывы, телефон и юридические тексты необходимо подтвердить у владельца. Бронирование и оплата не подключены. В проекте зафиксировано 32 компьютерных места: 20 Standard, 7 VIP и 5 Bootcamp. Адрес, круглосуточный режим и акция «пополни на 300 ₽ — получи 100 бонусов» перенесены из исходных материалов заказчика.

Основные редактируемые данные находятся в `src/data.ts`. Концептуальные изображения лежат в `public` и могут быть заменены реальными фотографиями без изменения компонентов.
